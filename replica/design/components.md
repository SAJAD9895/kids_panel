# Component specs: Kids Learning Platform

Draft 2026-11-17. Tokens: `tokens.json` (roles) → `tokens.css`, `tailwind.preset.cjs`, `flutter-tokens.json` (generated by `build_tokens.py`).
Sources: component lists in `replica/recon.md` and `docs/reconnaissance/screenshot-analysis.md` (SS-01…SS-19), screen IDs from `docs/reconnaissance/screen-inventory.md`.

**Status:** specs + a standalone visual check (`preview/index.html` → `preview/design-check.png`, rendered only from `tokens.css`). The production primitives (Flutter widget gallery, React `/design` route) are application code and wait for your approval of the architecture.

## 0. Ground rules

| topic | rule |
| --- | --- |
| what we copy | patterns and behaviour: a floating tab bar, a label pill on cards, a heart button overlapping the card edge, a birth-year gate keypad. Not art, characters, logos, copy, sounds or the original's colours |
| colours | roles only; values are placeholders (teal / orange / green / blue tab themes, **not** the original's purple / crimson / magenta) until `/replica-brand` |
| fonts | Nunito (kids surfaces, all headings), Inter (parent and admin body text); both SIL OFL. The original's font is not used |
| icons | **Lucide** (ISC licence): `lucide-react` on the web, the Flutter Lucide port in the app. Kids-tab icons are **our own commissioned illustrations** (content track C1), not 3D copies of theirs |
| illustrations, characters, mascots, sounds | original, commissioned (C1). Placeholders are plain shapes with text, never traced art |
| copy | written fresh. Labels in this file are working names, not the original's text |
| children's ergonomics | tap targets ≥ 56 dp (`size.tap-min-kids`); no text-only buttons for pre-readers (icon + voice prompt); no long-press or double-tap required; every kid button plays a short sound and has a 120 ms press animation |
| parents' ergonomics | targets ≥ 44 dp; WCAG 2.2 AA; works at 200 % text size |
| motion | `fast` 120 ms (press), `base` 200 ms (transitions), `playful` 320 ms + `spring` easing (rewards). Reduced-motion turns all of it off |
| theming in the Kids Area | one shell, re-coloured per tab via `kids-<tab>-bg` / `kids-<tab>-bar` [V SS-01, 04, 11]. Lessons has a light theme (`kids-lessons-bg`, dark text) [V SS-07, 10] |
| no opacity for state | locked, retry and inactive states change border, icon or background, **never the text's opacity**: dimming to 50 % dropped labels below AA in the visual check. Exception: truly disabled controls (WCAG exempts them) |
| orientation | Kids Area landscape; Parents Area portrait on phones [V SS-16]; games per template [V SS-12] |

State legend: **seen** = in the screenshots or recon; **added** = needed but not seen (we must design it).

## 8. Flutter mapping (kl_design)

`flutter-tokens.json` feeds a generated `ThemeExtension` in `packages/dart/kl_design` once development starts:

| token group | Flutter target |
| --- | --- |
| `color.*` (parent) | `ColorScheme` (primary = accent, onPrimary = on-accent, surface, error = danger …) + `KlColors` extension for the extra roles |
| `color.kids.*` | `KidsTheme` extension, one instance per tab (`play`, `theater`, `playtogether`, `lessons`), switched by the shell |
| `type`, `type-kids` | `TextTheme` (Inter body, Nunito headings) + `KidsTextTheme` (Nunito) |
| `space`, `radius`, `size` | `KlSpacing`, `KlRadius`, `KlSizes` constants; `size.tap-min-kids` enforced by the kid button widgets |
| `motion` | `KlMotion` durations; all become `Duration.zero` when `MediaQuery.disableAnimations` is true |
