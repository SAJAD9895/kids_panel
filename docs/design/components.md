# Component specs: Kids Learning Platform

v1.0, 2026-11-18. Moved from `replica/design/components.md` and aligned with design v1.0 (rail navigation, `docs/design/tokens/tokens.json`) in the design review (`docs/review/design-review.md`).
Tokens: `tokens/tokens.json` (roles) → `tokens/tokens.css`, `tokens/tailwind.preset.cjs`, `tokens/flutter_tokens.json` (generated by `tokens/build_tokens.py`). Role names below are v1.0 names: parent/admin roles are `ui-*` / `admin-*`, children's roles are `kids-*` with one colour family per rail section (`kids-<section>-fill | -soft | -ink`, section ∈ play (Home), learn, watch, listen, me).
Sources: component lists in `replica/recon.md` and `docs/reconnaissance/screenshot-analysis.md` (SS-01…SS-19), screen IDs from `docs/reconnaissance/screen-inventory.md`.

**Status:** specs + a standalone visual check (`preview/index.html` → `preview/design-check.png`, rendered only from `tokens.css`). The production primitives (Flutter widget gallery, React `/design` route) are application code and wait for your approval of the architecture.

## 0. Ground rules

| topic | rule |
| --- | --- |
| what we copy | patterns and behaviour: a horizontally scrolling card row, a type chip on cards, a save button on the card, a grown-up keypad gate. Not art, characters, logos, copy, sounds or the original's colours |
| colours | roles only; values are placeholders (teal / orange / green / blue tab themes, **not** the original's purple / crimson / magenta) until `/replica-brand` |
| fonts | Nunito (kids surfaces, all headings), Inter (parent and admin body text); both SIL OFL. The original's font is not used |
| icons | **Lucide** (ISC licence): `lucide-react` on the web, the Flutter Lucide port in the app. Kids-tab icons are **our own commissioned illustrations** (content track C1), not 3D copies of theirs |
| illustrations, characters, mascots, sounds | original, commissioned (C1). Placeholders are plain shapes with text, never traced art |
| copy | written fresh. Labels in this file are working names, not the original's text |
| children's ergonomics | tap targets ≥ 64 dp (`size.tap-kids`; secondary 56 `tap-kids-secondary`, gap 12 `tap-gap-kids`); no text-only buttons for pre-readers (icon + voice prompt); no long-press or double-tap required; every kid button plays a short sound and has a 120 ms press animation |
| parents' ergonomics | targets ≥ 44 dp; WCAG 2.2 AA; works at 200 % text size |
| motion | `motion.fast` (press), `motion.base` (transitions), `motion.celebrate` + `ease-bounce` (rewards). Reduced motion or the Calm motion switch (K20) turns all of it off |
| theming in the Kids Area | one light shell (`kids-bg`, text `kids-ink`); the active rail section tints selected items and headers with `kids-<section>-soft` / `-fill`. Not the original's dark, saturated per-tab backgrounds [V SS-01, 04, 11] |
| no opacity for state | locked, retry and inactive states change border, icon or background, **never the text's opacity**: dimming to 50 % dropped labels below AA in the visual check. Exception: truly disabled controls (WCAG exempts them) |
| orientation | Kids Area landscape on phones, both on tablets and web (README §4); Parents Area portrait on phones [V SS-16]; games per template [V SS-12] |

State legend: **seen** = in the screenshots or recon; **added** = needed but not seen (we must design it).

## 8. Flutter mapping (kl_design)

`tokens/flutter_tokens.json` feeds a generated `ThemeExtension` in `packages/dart/kl_design` once development starts:

| token group | Flutter target |
| --- | --- |
| `color.ui.*` (parent) | `ColorScheme` (primary = ui-primary, onPrimary = ui-on-primary, surface, error = ui-danger …) + `KlColors` extension for the extra roles |
| `color.kids.*` | `KidsTheme` extension with one `KidsSection` colour set per rail section (`play`/Home, `learn`, `watch`, `listen`, `me`), picked by the shell |
| `type`, `type-kids` | `TextTheme` (Inter body, Nunito headings) + `KidsTextTheme` (Nunito) |
| `space`, `radius`, `size` | `KlSpacing`, `KlRadius`, `KlSizes` constants; `size.tap-kids` enforced by the kid button widgets |
| `motion` | `KlMotion` durations; all become `Duration.zero` when `MediaQuery.disableAnimations` is true |
